# Suggestions (not built)

Ideas from looking at family wall calendars such as Cozyla:
- Chores and routines with stars and rewards for the children, per person.
- Shared lists (shopping, to-do), maybe filled from the meal plan.
- Photo frame / screensaver when the dashboard is idle.
- Weather and a daily summary widget.
- Several members on one event (for example "Alex and Sam").
- Recurring events (weekly training, school days).
- Day view and a "today" screen for phones.
- A first-start screen to set the code in the browser (needed before the Pi image).
- Import from calendars (Google, Apple, Outlook) and Aula directly.
- Budget as its own app (open question for the owner).
